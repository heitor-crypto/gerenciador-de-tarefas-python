# Gerenciador de Tarefas em Python

Criei este projeto para colocar em prática o que venho aprendendo em Python, principalmente sobre listas, condições e estruturas de repetição.

É um gerenciador de tarefas simples, que funciona pelo terminal e permite adicionar, visualizar e remover tarefas.

## O que o programa faz?

- Adiciona novas tarefas.
- Mostra as tarefas cadastradas.
- Remove tarefas da lista.
- Impede que tarefas vazias sejam adicionadas.
- Avisa quando uma opção é inválida.

## O que utilizei?

Durante o desenvolvimento, pratiquei alguns conceitos de Python:

- Listas e variáveis.
- Condições com `if`, `elif` e `else`.
- Repetição com `while True`.
- Métodos como `append()`, `remove()` e `strip()`.
- Entrada de dados com `input()`.

## Como executar

É necessário ter o Python instalado.

1. Baixe o arquivo `gerenciador.py`.
2. Abra o terminal na pasta onde o arquivo está salvo.
3. Execute:

```bash
python gerenciador.py
```

## Observação

Por enquanto, as tarefas ficam salvas apenas enquanto o programa está aberto. Ao fechar, a lista é apagada.
