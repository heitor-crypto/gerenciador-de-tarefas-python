# Gerenciador de Tarefas em Python

Este projeto foi desenvolvido durante meus estudos de Python, com o objetivo de praticar lógica de programação e aprender a trabalhar com listas, condições e estruturas de repetição.

O programa funciona pelo terminal e permite gerenciar tarefas de maneira simples e interativa.

## Funcionalidades

- Adicionar novas tarefas.
- Visualizar as tarefas cadastradas.
- Remover tarefas existentes.
- Impedir o cadastro de tarefas vazias.
- Identificar opções inválidas no menu.
- Encerrar o programa quando solicitado.

## Tecnologias e conceitos utilizados

- Python
- Listas e variáveis
- Estruturas condicionais (`if`, `elif` e `else`)
- Laço de repetição (`while`)
- Métodos `append()`, `remove()` e `strip()`
- Entrada de dados com `input()`

## Como executar

1. Tenha o Python 3 instalado.
2. Baixe o arquivo `gerenciador.py`.
3. Abra o terminal na pasta do projeto.
4. Execute o comando `python gerenciador.py`.

## Observação

As tarefas ficam armazenadas temporariamente na memória do programa e são apagadas quando ele é encerrado.
